# PSAT Package Repository

본 저장소는 성균관대학교 통계분석학회 PSAT에서 수행한 과제로 구성되어 있습니다.

---

## 포함된 파일 및 주요 내용

---

### 1. PSAT_Package_Week1.ipynb
- **주제:** EDA, Tree Model and its interpretation

---

### 2. PSAT_Package_Week2.ipynb
- **주제:** SQL, Modeling, Distribution Analysis

---

### 3. PSAT_Package_Week3.ipynb
- **주제:** Graph Data Analysis and Recommendation System

---

### 4. PSAT_PACKAGE_TOPIC3.ipynb
- **주제:** Chatbot
- **주요 내용:**
  - 사용자 및 애니메이션 데이터를 기반으로 K-means를 사용한 클러스터링 수행
  - Link Prediction 기법 (e.g., Katz Index, Preferential Attachment)을 활용한 추천 모델 구현
  - 그래프 네트워크 분석 및 시각화:
    - 사용자-애니메이션 관계를 그래프로 나타냄
    - 중심성 분석을 통한 애니메이션의 중요도 측정
